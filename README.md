# Airbnb Listings

A web application that displays Airbnb listings in San Francisco. The listing
data is loaded from a JSON file using the JavaScript Fetch API and rendered
dynamically to the page.

## Features

- Displays the first 50 Airbnb listings from the provided JSON dataset
- Shows the listing name, description, price, amenities and thumbnail
- Shows the host's name and profile photo
- Live search by listing name
- Show and hide amenities for individual listings
- Responsive layout for different screen sizes
- Back to Top navigation

## Technologies Used

- HTML
- CSS
- JavaScript
- Bootstrap
- Fetch API

## How to Run

Run the project using a local web server and open `index.html` through the
server. A local server is required because the application loads the JSON data
using `fetch()`.
